# Стек десктопного приложения

Уходим от веб-сервиса к обычному приложению для macOS и Windows. Основа: Tauri 2, ядро на Rust, интерфейс оставляем на React.

## Что берём

| Часть | Технология |
|---|---|
| Оболочка | Tauri 2 |
| Интерфейс | React, TypeScript, Vite, zustand (как сейчас) |
| Карта | MapLibre GL JS (как сейчас) |
| Чтение и запись .osm | Rust, quick-xml |
| Граф и проверки | Rust, petgraph |
| Геометрия, поиск ближайших объектов | geo, rstar |
| Связь интерфейса с Rust | команды Tauri, serde, tauri-specta для типов TS |
| Открытие и сохранение файлов | tauri-plugin-dialog, tauri-plugin-fs |
| Тесты | cargo test для ядра, vitest для интерфейса |
| Сборка под Mac и Windows | GitHub Actions, tauri-action |

## Почему Tauri

Почти весь интерфейс и карта переезжают без переписывания. Приложение весит около 10 МБ, потому что Tauri использует системный движок отрисовки и не тащит с собой Chromium. На маке это WebKit, на Windows WebView2. Пользователь видит обычное окно, браузера и адресной строки нет.

Чистый Rust GUI (egui, Iced, Slint) рассматривали. Отказались, потому что пришлось бы с нуля делать карту с подложкой, спутником и перетаскиванием узлов. Готового аналога MapLibre на Rust нет, а времени на это у нас нет.

## План переноса

1. Обернуть текущий фронт в Tauri. После этого уже есть рабочее приложение на обеих системах.
2. Переносить src/osm/ в Rust по частям. Первыми идут парсинг, сохранение и проверки графа, правки пока остаются на фронте.
3. Перенести в Rust тест на сохранение без потерь (example.osm туда и обратно).

## Что проверить на обеих системах

Вёрстка в WebKit и WebView2 иногда отличается в мелочах (шрифты, прокрутка), поэтому каждую сборку смотрим и на маке, и на Windows.

Горячие клавиши сейчас завязаны на Ctrl. На маке нужно добавить Cmd.

Без подписи macOS при первом запуске пишет про неизвестного разработчика, а Windows показывает SmartScreen. Для хакатона это терпимо, для раздачи людям понадобится аккаунт Apple Developer и сертификат для Windows.

WebView2 обычно уже стоит в Windows 10 и 11. Если его нет, установщик Tauri поставит его сам.

На слабых ноутбуках большой граф в WebGL может тормозить. Если упрёмся, упростим слои на мелких масштабах.

## Открытые вопросы

Нужна ли работа без интернета. Сейчас подложка грузится онлайн, для офлайна можно взять локальные тайлы PMTiles.

Какого размера будут файлы: фрагмент или весь Иркутск. От этого зависит, сколько логики переносить в Rust.
