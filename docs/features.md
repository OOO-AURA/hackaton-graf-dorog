# Фичи редактора и зачем они

Каждый эксперт жюри ставит балл за фичу, если убеждён в её пользе для редактора графа. Ниже у каждой фичи одна фраза «зачем», как её показать и цифра с фрагмента из задания, если она есть.

## Точность графа для MATSim, SUMO и Webots

| Фича | Зачем | Как показать | Цифра |
|---|---|---|---|
| Сохранение без потерь | Здания, трамвай, маршруты и атрибуты остаются в файле, Webots строит по ним 3D | Открыть `example.osm` и сохранить без правок: файл идентичен (тест) | 6089 узлов, 1392 линии, 187 отношений |
| Проверка графа с кнопкой «Исправить» | MATSim и SUMO молча выкидывают тупики и не видят перекрёстков без общего узла | Вкладка «Валидация» на примере | 3 разорванных перекрёстка → 0 |
| Кордонные связи на краю фрагмента | Односторонняя дорога, обрезанная краем, для MATSim тупик, и он выкидывает её целиком | «Замкнуть кордон» и проверка на сервере | MATSim теряет 4 линка вместо 23 |
| Ложные тоннели под мостами | Webots не строит дороги с `layer<0`, под мостом остаётся дыра, машины SUMO едут по пустоте | Объездная под мостом Лермонтова, кнопка «Исправить» | Webots: 543 дороги вместо 540 |
| Повороты, как Turns в Visum | Запреты поворотов меняют движение на перекрёстке, SUMO их применяет | Инспектор перекрёстка, снять галочку «налево» | Пишется стандартный `type=restriction` |
| Маршрут «отсюда — сюда» | Сразу видно, разрезана ли сеть направлениями, до прогона MATSim | Узел на Объездной → узел на Лермонтова и обратно | Длина, время, улицы или «проехать нельзя» |
| Раскраска по атрибуту, как в Visum | Скачки полос и пустые скорости видны на карте за секунду | Переключатель «Цвет: пропуски атрибутов» | Объездная: 2, 3, 4 полосы на соседних участках |
| Профиль дороги по СП | Пропускная способность и скорость по нормам, а не на глаз | Инспектор дороги, «Привести к норме» | СП 42.13330, СП 34.13330 |
| Улица целиком | Улицу из 15 участков правят одним действием и без скачка пропускной способности посередине | Список улиц → Объездная | 2400–4800 авт/ч вдоль одной улицы |
| Здания для 3D | Webots строит здания по этажности и крыше, а в примере высоты нет ни у одного здания | Клик по корпусу ИРНИТУ, «Высота по этажам», 3D | 0 из 365 зданий с высотой |
| Мост в 3D как настоящий | Видно, что путепровод проходит над дорогой и железной дорогой на той высоте, что поставит Webots | 3D (клавиша P) у моста Лермонтова | Настил на 5 м, насыпь 70 м, опоры |

## Скорость и удобство работы

| Фича | Зачем | Как показать |
|---|---|---|
| Горячие клавиши в любой раскладке | Правка без мыши и без переключения языка | V, D, N, T, R, F, S, X, 1–6 |
| Шаблоны дорог | Новая дорога сразу с классом, полосами и скоростью | Клавиши 1–6 |
| Перетаскивание узла на узел | Разорванный перекрёсток склеивается одним движением | Перетащить узел съезда на Объездную |
| Отмена, журнал правок | К любому шагу можно вернуться, видно, что меняли | Вкладка «Журнал» |
| Карта и список изменений | Отвечает на вопрос «что вы поменяли и где» | Слой «Изменения», выгрузка `.md` |
| Черновик и восстановление после сбоя | Правки не теряются | Закрыть приложение без сохранения |
| Подложка: схема и спутник | Сверка графа с реальностью | Переключатель «Схема / Спутник» |

## Моделирование прямо в редакторе

| Фича | Зачем | Как показать |
|---|---|---|
| Проверка как на сервере | Тот же SUMO, MATSim и Webots, что у организаторов, до отправки файла | Кнопка в шапке |
| «Было → стало» в проверке | Готовая таблица для защиты: что правки дали на каждом уровне | «Сравнить с исходным файлом» |
| Потоки: зоны, матрица, равновесие | Видно, где сеть не справится в час пик и как правка меняет загрузку | Вкладка «Потоки» |
| Пучок потоков, как Flow bundle в Visum | Чьи поездки идут по дороге, кого заденет правка | Выбрать Объездную, «Кто едет по…» |
| Микро: SUMO на карте | Очереди, светофоры, уровень обслуживания по каждой дороге | Переключатель «Микро» |
| Сценарии | Сравнение двух версий графа в одной таблице | Вкладка «Сценарии» |
| Отчёт HTML | Все показатели и карта в одном файле для жюри | «Экспорт → Отчёт» |

## Воспроизводимость на весь город

| Фича | Зачем | Цифра |
|---|---|---|
| «Из OSM»: любой район или город | Редактор не привязан к фрагменту, данные те же, что у организаторов | Скачанный фрагмент даёт те же цифры, что `example.osm` |
| Режим «только дороги» для города | Город со зданиями весит сотни мегабайт | Иркутск целиком: 97 тыс. узлов, 24 МБ |
| Большие графы | Проверка в фоне, длинные списки рисуются частями | Иркутск открывается за 1,4 с, проверка за 3,1 с |
| Установщики macOS и Windows | Жюри запускает без сборки окружения | GitHub Actions |
