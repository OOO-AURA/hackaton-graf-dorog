# Лицензии шрифтов

Шрифты лежат в `public/fonts` и подключаются локально, приложению не нужен интернет. Все пять распространяются по SIL Open Font License 1.1: https://openfontlicense.org

| Шрифт | Где в интерфейсе | Авторы |
|---|---|---|
| Big Shoulders Display | заголовки, латиница и цифры | Patric King |
| Fira Sans Extra Condensed | заголовки, кириллица | Carrois Apostrophe, Mozilla |
| Albert Sans | основной текст, латиница | Andreas Rasmussen |
| Onest | основной текст, кириллица | Dmitri Voloshin |
| JetBrains Mono | теги OSM, id, цифры | JetBrains |

В Big Shoulders Display и Albert Sans нет кириллицы, поэтому русские буквы берутся из Fira Sans Extra Condensed и Onest. Файлы взяты из пакетов Fontsource (подмножества latin, latin-ext и cyrillic в формате woff2) без изменений.
